## 代码审查后的修复（4 项）

1. **engine.js 复制-移动检测失效（真 bug）**：`for (var vi = 0; varr === 0 && vi < ...)` 的循环条件让方差只累加首项却仍除以 64，方差被系统性低估，所有块都撞上过滤阈值 → 该检测器从不触发。去掉 `varr === 0 &&`。
   - 顺带重新标定阈值：原 2500 实测无一块能通过（块方差中位数仅 ~61、p90 ~112）。用 tools/png.js 在 Node 侧复算块方差分布并跑完整匹配流程，100 → 12 张误报 9 张（合成图周期纹理），900 → 仅剩 5~7 个候选块，**最终取 400（零误报 + 约 13~14 个候选块）**。

2. **README.md 融合公式与代码不符**：文档写 `1−(1−p_img)(1−p_txt)(1−0.8·p_cross)`，agent.js 实为无 0.8 阻尼。已改为与代码一致，并补上三处权重修正（低置信 0.42 折半 / 文体类 0.82 降权 / 交叉证据不阻尼）。

3. **selftest.js 档位歧义**：CASES 里样本 B 期望 `medium`，README 页面实测 57 分 `high`，易被误读为矛盾。加了注释说明二者不同源（Node 跑不了 Canvas 图像取证，只有文本 + 跨模态证据），并把 case 名改成「样本 B · 拼接篡改（仅文本侧）」。

4. **benchmark.js 图文配对是循环取模**：新增支持 manifest 样本的可选字段 `text_case` 显式配对，未指定时退回取模并标记 `pairing=roundrobin` / `fallback`；row 与无头日志都带上 pairing。文档同步（benchmark.md 新增「图文配对」节、dataset.md 字段表加 `text_case`）。

**未处理**：`dataset/manifest.json` 的 `synthetic: true` 不是代码问题，必须真人拍摄 + 真实 AIGC 素材到位后才能翻成 false，否则图像侧指标无意义。
